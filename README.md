# Estudos-para-analista-de-dados

## Guia de estudos para a área de análise de dados

### Objetivos
* Alinhar os conteúdos necessários para a formação de análise de dados;
* Identificar as fontes de informação necessárias juntamente com as ferramentas;
* Estabelecer conexão com a teoria aprendida na prática de atividades relacionadas as tendências de mercado público e/ou privado.

## Fontes de informação
A procura dos conteúdos necessários é baseado nas buscas no google por meio da palavra-chave "análise de dados" e, posteriormente verificação se o conteúdo é pertinente com os objetivos definidos.
